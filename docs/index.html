    07 / FUND SCREEN

    Where the SIP goes.

    Top three by three-year return in each category, from AMFI daily NAV via api.mfapi.in. Direct plans only — same portfolio, same manager, without the distributor commission. Returns are computed from the published NAV series, not copied off a factsheet.

    On expense ratio. Per-scheme TER is not published in the free AMFI feed, so this screen does not claim to know it. The cost lever that is visible is Direct versus Regular, and it is the big one: a Regular plan carries the distributor commission inside its TER, typically 0.5–1.2% a year more for the same portfolio. Everything below is Direct.
